Data quality: missing curves

Missingness is per well (whole curves absent), so mean imputation would mislead. The model handles NaN natively.

Key findings

  • Accuracy hides the picture. Class weighting lowered accuracy but improved rare-class recognition.
  • Window size matters. Wide rolling windows (~15 m) blurred thin beds: Halite F1 0.53 with windows (25, 100) vs 0.79 with (5, 25).
  • Confidence filtering backfired. About 98% of Tuff labels are lowest-confidence, so filtering removed nearly all Tuff examples.
  • Validate by well. Random row splits leak neighbouring samples and inflate scores.

Limitations

  • Dolomite and Basement are essentially not learned (very few examples).
  • “Sandstone/Shale” is a mixed class and inherently ambiguous.
  • Lithology is rock type, not hydrocarbon detection.
  • Scores are not comparable to the official FORCE 2020 leaderboard (different metric and split).
